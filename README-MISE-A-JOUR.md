# Mise à jour Fioles

Cette version ajoute à Fioles la suppression de produits, les prises groupées et la suppression d’une prise avec restitution automatique de la quantité au stock. Aucune fonctionnalité de notification n’est incluse.

## Installation
1. Remplace les fichiers du site avec le contenu de cette archive.
2. Dans Supabase SQL Editor, exécute `migration-fioles-v2.sql` après la migration initiale `migration-fioles.sql`.
3. Déploie le site en HTTPS.

Cette archive n’a pas été publiée sur GitHub. La connexion réelle à Supabase doit être vérifiée après installation.
